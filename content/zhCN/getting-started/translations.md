## 安装
1. 从给定的链接下载 zip 文件。
2. 解压该文件夹，如果原文件夹名称不是 `GadgetsMenu`，请将其重命名为 `GadgetsMenu`。
3. 删除 `plugins/` 文件夹中旧的 `GadgetsMenu` 文件夹，并用您解压出来的新文件夹替换它。
4. 请确保解压出来的文件夹中的 `config.yml` 文件也一并被替换，否则部分文件将会损坏。


如果您已经将 GadgetsMenu 的配置翻译成了列表中没有的语言，或者列表中的译本已经过时，并且您愿意分享，请告知我们的支持团队。您可以在 GitHub 问题追踪器上提交问题，或在我们的 GadgetsMenu Discord 服务器中分享，我们的支持团队将协助您，并把您的译本添加到列表中。
